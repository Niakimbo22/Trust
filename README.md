# Trust

Application Android personnelle de **Bible audio catholique** : un vrai lecteur audio biblique, précis au verset près.

- Texte : Bible Crampon 1923 (domaine public).
- Audio : enregistrements Mission Web (CC BY-NC-ND), diffusés sans modification.
- Gratuit, sans publicité ni pistage.

## Installer
Télécharge le dernier APK dans [Releases](https://github.com/Niakimbo22/trust/releases/latest). Ensuite, l'app se met à jour toute seule (Réglages → Mises à jour).

## Publier une version
Créer un tag `vX.Y.Z` (ou lancer le workflow **Release** à la main) : la CI build l'APK signé et crée la release.
